## 常见问题排查

### 问题 1: 找不到可执行文件

**症状**:
```bash
$ ls /tmp/opencode_test/opencode
ls: cannot access '/tmp/opencode_test/opencode': No such file or directory
```

**解决方案**:
```bash
# 从本地重新传输文件
cd /media/hzm/data_disk/opencode
scp packages/opencode/dist/opencode-linux-x64/bin/opencode hzm@10.200.1.59:/tmp/opencode_test/opencode
```

### 问题 2: 权限被拒绝

**症状**:
```bash
$ ./opencode --version
bash: ./opencode: Permission denied
```

**解决方案**:
```bash
chmod +x /tmp/opencode_test/opencode
```

### 问题 3: 找不到动态库

**症状**:
```bash
$ ./opencode --version
./opencode: error while loading shared libraries: libc.so.6: cannot open shared object file
```

**解决方案**:
- 检查系统是否有必要的库：`ldd opencode`
- 如果缺少库，可能需要安装：`sudo apt-get install libc6`

### 问题 4: 命令执行失败

**症状**:
```bash
$ ./opencode --version
[错误信息]
```

**解决方案**:
- 检查错误信息
- 确认文件完整性：`file opencode`
- 检查依赖：`ldd opencode`
- 查看详细错误：`./opencode --version 2>&1`
