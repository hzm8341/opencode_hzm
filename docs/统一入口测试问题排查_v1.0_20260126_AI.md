## 🔍 问题：unified 命令未识别

### 问题现象

运行 `opencode unified` 时，显示帮助信息而不是执行命令，说明命令未被识别。

### 原因分析

1. **使用已安装的二进制文件**: `opencode` 命令指向全局安装的版本，不包含新添加的 `unified` 命令
2. **代码未重新构建**: 即使代码已修改，如果没有重新构建，新命令不会生效
3. **开发模式未启用**: 需要使用开发模式运行才能使用最新代码

---

## ✅ 解决方案

### 方案 1: 使用开发模式运行（推荐）

#### 方法 A: 直接使用 bun 运行

```bash
# 进入 OpenCode 目录
cd /media/hzm/data_disk/opencode/packages/opencode

# 使用开发模式运行
bun run --conditions=browser ./src/index.ts unified \
  --dir /tmp/test-project \
  --requirement "测试需求"
```

#### 方法 B: 使用测试脚本（已更新）

测试脚本 `test-unified.sh` 已更新，默认使用开发模式：

```bash
cd /media/hzm/data_disk/opencode
./test-unified.sh
```

### 方案 2: 重新构建项目

```bash
# 进入 OpenCode 目录
cd /media/hzm/data_disk/opencode/packages/opencode

# 构建项目
bun run build

# 然后使用构建后的版本
# 注意：需要确保构建后的二进制包含新命令
```

### 方案 3: 创建开发环境别名

在 `~/.bashrc` 或 `~/.zshrc` 中添加：

```bash
# OpenCode 开发模式别名
alias opencode-dev='cd /media/hzm/data_disk/opencode/packages/opencode && bun run --conditions=browser ./src/index.ts'
```

然后使用：

```bash
opencode-dev unified --dir /tmp/test --requirement "测试"
```

## 🔧 验证命令是否可用

### 检查命令注册

```bash
# 使用开发模式查看帮助
cd /media/hzm/data_disk/opencode/packages/opencode
bun run --conditions=browser ./src/index.ts --help | grep unified
```

应该看到 `unified` 命令在列表中。

### 检查代码是否正确

```bash
# 检查命令文件是否存在
ls -la /media/hzm/data_disk/opencode/packages/opencode/src/cli/cmd/unified.ts

# 检查是否已导入
grep -n "UnifiedCommand" /media/hzm/data_disk/opencode/packages/opencode/src/index.ts

# 检查是否已注册
grep -n ".command(UnifiedCommand)" /media/hzm/data_disk/opencode/packages/opencode/src/index.ts
```

## 🐛 常见问题

### Q1: 命令仍然未识别

**检查**:
1. 确认代码已保存
2. 确认 `UnifiedCommand` 已正确导入和注册
3. 使用开发模式运行

**解决**:
```bash
# 检查导入
grep "import.*UnifiedCommand" packages/opencode/src/index.ts

# 检查注册
grep ".command(UnifiedCommand)" packages/opencode/src/index.ts

# 如果都没有，需要重新添加
```

### Q2: 运行时出现模块未找到错误

**解决**:
```bash
cd /media/hzm/data_disk/opencode/packages/opencode
bun install
```

### Q3: 权限错误

**解决**:
```bash
chmod +x /media/hzm/data_disk/opencode/test-unified.sh
chmod +x /media/hzm/data_disk/opencode/packages/opencode/bin/opencode
```
