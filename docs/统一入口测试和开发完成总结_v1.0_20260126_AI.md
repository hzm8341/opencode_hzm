  - 第2次错误：自动重试
  - 第3次错误：升级到用户

- ✅ 错误记录到规划文件（Manus 模式）
- ✅ 错误上下文管理

**使用示例**:
```typescript

const result = await errorHandler.handleError(error, {
  task: 'task-id',
  phase: 'Phase 1: 需求分析',
  sessionID: 'session-id',
})

if (result.shouldRetry) {
  // 自动重试
} else if (result.shouldEscalate) {
  // 需要用户介入
}
```

## 🚀 使用示例

### 完整工作流示例

```typescript
import { unifiedEntry } from '@opencode-ai/opencode/unified'

// 执行统一入口
const result = await unifiedEntry({
  directory: '/path/to/project',
  requirement: '实现用户登录功能，包括前端和后端',
  sessionID: 'session-id',
})

if (result.success) {
  console.log('✅ 任务成功')
  console.log('Session ID:', result.sessionID)
  console.log('Message ID:', result.messageID)
  console.log('规划文件已创建:', result.planningFilesCreated)
  
  if (result.executionPlan) {
    console.log('执行计划:', result.executionPlan)
  }
} else {
  console.error('❌ 任务失败:', result.error?.message)
  
  // 错误已通过 3-Strike 协议处理
  // 如果失败 3 次，需要人工介入
}
```
