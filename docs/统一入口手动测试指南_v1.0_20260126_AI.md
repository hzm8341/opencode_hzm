## 📋 测试前准备

### 1. 环境检查

```bash
# 检查 Bun 是否安装
bun --version

# 检查 Node.js 版本（如果需要）
node --version

# 进入项目目录
cd /media/hzm/data_disk/opencode/packages/opencode

# 安装依赖（如果还没有安装）
bun install
```

### 2. 构建项目

```bash
# 构建 OpenCode
bun run build

# 或者直接运行开发模式
bun run dev
```

### 3. 准备测试目录

```bash
# 创建测试目录
mkdir -p /tmp/opencode-test
cd /tmp/opencode-test

# 创建一个简单的测试项目
mkdir test-project
cd test-project

# 创建一个 package.json（用于项目检测测试）
cat > package.json << 'EOF'
{
  "name": "test-project",
  "version": "1.0.0",
  "dependencies": {
    "express": "^4.18.0"
  }
}
EOF
```

## 🔍 详细验证步骤

### 1. 验证规划文件创建

```bash
# 检查文件是否存在
test -f task_plan.md && echo "✅ task_plan.md 存在" || echo "❌ task_plan.md 不存在"
test -f findings.md && echo "✅ findings.md 存在" || echo "❌ findings.md 不存在"
test -f progress.md && echo "✅ progress.md 存在" || echo "❌ progress.md 不存在"

# 检查文件内容格式
grep -q "# Task Plan" task_plan.md && echo "✅ task_plan.md 格式正确" || echo "❌ task_plan.md 格式错误"
grep -q "# Findings" findings.md && echo "✅ findings.md 格式正确" || echo "❌ findings.md 格式错误"
grep -q "# Progress" progress.md && echo "✅ progress.md 格式正确" || echo "❌ progress.md 格式错误"
```

### 2. 验证项目检测

```bash
# 在 Node.js 项目中
cd /tmp/opencode-test/test-project
opencode unified --dir . --requirement "检测项目" 2>&1 | grep -i "node\|express" && echo "✅ 项目检测正确"

# 在 Python 项目中
cd /tmp/opencode-test/python-project
opencode unified --dir . --requirement "检测项目" 2>&1 | grep -i "python" && echo "✅ 项目检测正确"
```

### 3. 验证错误处理

```bash
# 创建一个会导致错误的测试
cd /tmp/opencode-test/test-project

# 运行并观察错误处理
opencode unified \
  --dir . \
  --requirement "执行一个会失败的操作" \
  --useManus

# 检查错误记录
if [ -f task_plan.md ]; then
  error_count=$(grep -c "### Attempt" task_plan.md || echo "0")
  echo "错误尝试次数: $error_count"
  if [ "$error_count" -ge 3 ]; then
    echo "✅ 3-Strike 协议正常工作"
  fi
fi
```

### 4. 验证进度跟踪

```bash
# 运行一个任务
cd /tmp/opencode-test/test-project
opencode unified \
  --dir . \
  --requirement "执行一个多步骤任务" \
  --useManus

# 检查进度文件
if [ -f progress.md ]; then
  progress_entries=$(grep -c "## " progress.md || echo "0")
  echo "进度条目数: $progress_entries"
  if [ "$progress_entries" -gt 0 ]; then
    echo "✅ 进度跟踪正常工作"
  fi
fi
```

## 🐛 问题排查

### 问题 1: 命令未找到

**错误**: `command not found: opencode`

**解决方案**:
```bash
# 检查是否在正确的目录
cd /media/hzm/data_disk/opencode/packages/opencode

# 检查 bin 文件是否存在
ls -la bin/opencode

# 如果不存在，需要构建
bun run build

# 或者使用相对路径
./bin/opencode unified --dir /path/to/project --requirement "test"
```

### 问题 2: 依赖未安装

**错误**: `Cannot find module 'proper-lockfile'`

**解决方案**:
```bash
cd /media/hzm/data_disk/opencode/packages/opencode
bun install
```

### 问题 3: 权限错误

**错误**: `Permission denied` 或 `EACCES`

**解决方案**:
```bash
# 检查目录权限
ls -la /tmp/opencode-test/test-project

# 确保有写入权限
chmod -R 755 /tmp/opencode-test/test-project

# 或者使用其他目录
mkdir -p ~/opencode-test
cd ~/opencode-test
```

### 问题 4: 规划文件未创建

**可能原因**:
1. 需求不够复杂，未触发 Manus 模式
2. 目录权限问题
3. 文件系统错误

**解决方案**:
```bash
# 强制使用 Manus 模式
opencode unified --dir . --requirement "test" --useManus

# 检查目录权限
ls -la .

# 检查磁盘空间
df -h .
```

### 问题 5: SessionPrompt 错误

**错误**: `promptWithManus is not a function`

**解决方案**:
```bash
# 检查代码是否正确编译
cd /media/hzm/data_disk/opencode/packages/opencode
bun run build

# 检查 prompt.ts 文件
grep -n "promptWithManus" src/session/prompt.ts
```

## 🎯 快速测试脚本

创建一个快速测试脚本：

```bash
#!/bin/bash
# 快速测试脚本

TEST_DIR="/tmp/opencode-test/test-project"
mkdir -p "$TEST_DIR"
cd "$TEST_DIR"

echo "=== 测试 1: 简单需求 ==="
opencode unified --dir "$TEST_DIR" --requirement "帮我运行这个项目"
echo ""

echo "=== 测试 2: 复杂需求（Manus 模式）==="
opencode unified --dir "$TEST_DIR" --requirement "实现用户登录功能，包括前端和后端" --useManus
echo ""

echo "=== 测试 3: 检查规划文件 ==="
if [ -f task_plan.md ]; then
    echo "✅ task_plan.md 已创建"
    head -20 task_plan.md
else
    echo "❌ task_plan.md 未创建"
fi
echo ""

echo "=== 测试完成 ==="
```

保存为 `test-unified.sh`，然后运行：

```bash
chmod +x test-unified.sh
./test-unified.sh
```
