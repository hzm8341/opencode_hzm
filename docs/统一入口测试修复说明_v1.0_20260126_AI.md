## 🔧 修复的问题

### 问题 1: `ensureTitle` 函数缺少结束大括号

**错误信息**:
```
error: Unexpected export
    at /media/hzm/data_disk/opencode/packages/opencode/src/session/prompt.ts:1641:3
```

**原因**: `ensureTitle` 函数在 1635 行结束（`})`），但这是 `Session.update()` 的回调函数结束，而不是 `ensureTitle` 函数本身的结束。缺少了 `ensureTitle` 函数的结束大括号。

**修复**: 在 1635 行后添加 `ensureTitle` 函数的结束大括号 `}`。

**修复前**:
```typescript
        const title = cleaned.length > 100 ? cleaned.substring(0, 97) + "..." : cleaned
        draft.title = title
      })

  /**
   * 带 Manus 模式的 prompt（v5.0 新增）
   */
  export async function promptWithManus(input: {
```

**修复后**:
```typescript
        const title = cleaned.length > 100 ? cleaned.substring(0, 97) + "..." : cleaned
        draft.title = title
      })
  }

  /**
   * 带 Manus 模式的 prompt（v5.0 新增）
   */
  export async function promptWithManus(input: {
```
