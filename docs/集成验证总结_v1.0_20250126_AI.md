## 使用说明

### 在 OpenWork Desktop 中使用

1. **启动应用**:
   ```bash
   cd packages/openwork-desktop
   pnpm install  # 如果还没有安装依赖
   pnpm dev
   ```

2. **查看全局插件**:
   - 打开应用
   - 进入 Plugins 标签页
   - 切换到 "Global" scope
   - 应该能看到 `oh-my-opencode` 插件

3. **查看项目插件**:
   - 选择一个工作空间
   - 进入 Plugins 标签页
   - 切换到 "Project" scope
   - 插件通过 `.opencode/plugin/` 目录自动加载

4. **使用统一流程**:
   - 创建新会话
   - 输入: "帮我将当前的项目demo运行起来"
   - 系统会自动触发统一流程
