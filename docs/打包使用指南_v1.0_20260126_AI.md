## 概述

本指南介绍如何将 OpenCode 项目打包为 DEB（Linux）或 DMG（macOS）格式，以便手动安装测试。

---

## 前置要求

### 通用要求

1. **已构建可执行文件**
   - 确保已经运行过构建脚本生成可执行文件
   - 可执行文件位于 `packages/opencode/dist/` 目录

2. **Bun 运行时**
   - 项目使用 Bun 作为运行时
   - 确保已安装 Bun

### Linux (DEB) 要求

- **dpkg-deb 工具**
  ```bash
  sudo apt-get install dpkg-dev
  ```

- **系统要求**
  - Debian/Ubuntu 系统
  - 支持 amd64 或 arm64 架构

### macOS (DMG) 要求

- **macOS 系统**
  - 必须在 macOS 系统上构建 DMG
  - 系统自带 `hdiutil` 工具

## 快速开始

### 步骤 1: 构建可执行文件

首先需要构建可执行文件：

```bash
cd /media/hzm/data_disk/opencode/packages/opencode

# 构建当前平台的可执行文件
bun run script/build.ts --single

# 或构建所有平台
bun run script/build.ts
```

### 步骤 2: 打包

#### Linux - 打包为 DEB

```bash
cd /media/hzm/data_disk/opencode/packages/opencode

# 打包为 DEB（自动检测架构）
bun run script/package.ts --format deb

# 指定架构
bun run script/package.ts --format deb --arch amd64
bun run script/package.ts --format deb --arch arm64

# 或使用旧脚本（向后兼容）
bun run script/build_deb.ts
bun run script/build_deb.ts --arch amd64
```

#### macOS - 打包为 DMG

```bash
cd /media/hzm/data_disk/opencode/packages/opencode

# 打包为 DMG（自动检测架构）
bun run script/package.ts --format dmg

# 指定架构
bun run script/package.ts --format dmg --arch arm64
bun run script/package.ts --format dmg --arch x64

# 或使用旧脚本（向后兼容）
bun run script/build_dmg.ts
bun run script/build_dmg.ts --arch arm64
```

## 详细说明

### 统一打包脚本

**脚本位置**: `packages/opencode/script/package.ts`

**用法**:
```bash
bun run script/package.ts --format <deb|dmg> [--arch <arch>]
```

**参数说明**:
- `--format`: 打包格式，`deb` 或 `dmg`
- `--arch`: 架构（可选）
  - DEB: `amd64` 或 `arm64`
  - DMG: `arm64` 或 `x64`
  - 如果不指定，将自动检测当前系统架构

**示例**:
```bash
# Linux amd64
bun run script/package.ts --format deb --arch amd64

# Linux arm64
bun run script/package.ts --format deb --arch arm64

# macOS arm64
bun run script/package.ts --format dmg --arch arm64

# macOS x64
bun run script/package.ts --format dmg --arch x64
```

### DEB 打包

#### 输出位置

DEB 包将生成在：
```
packages/opencode/dist/opencode_<version>_<arch>.deb
```

例如：
- `packages/opencode/dist/opencode_1.1.4_amd64.deb`
- `packages/opencode/dist/opencode_1.1.4_arm64.deb`

#### 安装 DEB 包

```bash
# 安装
sudo dpkg -i packages/opencode/dist/opencode_1.1.4_amd64.deb

# 如果遇到依赖问题
sudo apt-get install -f

# 验证安装
opencode --version

# 卸载
sudo dpkg -r opencode
```

#### DEB 包内容

- `/usr/bin/opencode` - 可执行文件
- `/usr/share/doc/opencode/` - 文档目录
  - `README.md`
  - `LICENSE`

### DMG 打包

#### 输出位置

DMG 包将生成在：
```
packages/opencode/dist/opencode_<version>_<arch>.dmg
```

例如：
- `packages/opencode/dist/opencode_1.1.4_arm64.dmg`
- `packages/opencode/dist/opencode_1.1.4_x64.dmg`

#### 安装 DMG 包

1. **双击 DMG 文件**打开
2. **复制可执行文件**到系统路径：
   ```bash
   sudo cp /Volumes/OpenCode/opencode /usr/local/bin/
   ```
3. **或添加到 PATH**：
   ```bash
   export PATH="$PATH:/path/to/opencode"
   ```
4. **验证安装**：
   ```bash
   opencode --version
   ```

#### DMG 包内容

- `opencode` - 可执行文件
- `README.md` - 项目说明
- `INSTALL.txt` - 安装说明

## 完整工作流程示例

### Linux 完整流程

```bash
# 1. 进入项目目录
cd /media/hzm/data_disk/opencode/packages/opencode

# 2. 构建可执行文件
bun run script/build.ts --single

# 3. 打包为 DEB
bun run script/package.ts --format deb --arch amd64

# 4. 检查生成的包
ls -lh dist/opencode_*.deb

# 5. 安装测试（需要 sudo）
sudo dpkg -i dist/opencode_1.1.4_amd64.deb

# 6. 测试
opencode --version

# 7. 卸载
sudo dpkg -r opencode
```

### macOS 完整流程

```bash
# 1. 进入项目目录
cd /media/hzm/data_disk/opencode/packages/opencode

# 2. 构建可执行文件
bun run script/build.ts --single

# 3. 打包为 DMG
bun run script/package.ts --format dmg --arch arm64

# 4. 检查生成的包
ls -lh dist/opencode_*.dmg

# 5. 打开 DMG（双击或使用命令）
open dist/opencode_1.1.4_arm64.dmg

# 6. 安装
sudo cp /Volumes/OpenCode/opencode /usr/local/bin/

# 7. 测试
opencode --version
```

## 常见问题

### 问题 1: 可执行文件未找到

**错误信息**:
```
❌ Error: Executable not found at ...
```

**解决方案**:
1. 确保已运行构建脚本：
   ```bash
   bun run script/build.ts --single
   ```
2. 检查可执行文件是否存在：
   ```bash
   ls -lh dist/opencode-*/
   ```

### 问题 2: dpkg-deb 未找到（Linux）

**错误信息**:
```
❌ Failed to build DEB package
Make sure dpkg-deb is installed
```

**解决方案**:
```bash
sudo apt-get update
sudo apt-get install dpkg-dev
```

### 问题 3: DMG 只能在 macOS 上构建

**错误信息**:
```
❌ Error: DMG packages can only be built on macOS
```

**解决方案**:
- 必须在 macOS 系统上构建 DMG 包
- 如果需要在 Linux 上构建，可以考虑使用 Docker 或虚拟机

### 问题 4: 架构不匹配

**错误信息**:
```
package architecture (amd64) does not match system (arm64)
```

**解决方案**:
- 确保使用正确的架构参数
- 检查系统架构：
  ```bash
  uname -m
  ```

### 问题 5: 权限问题

**错误信息**:
```
Permission denied
```

**解决方案**:
- 安装 DEB 包需要 sudo 权限
- 确保有足够的权限执行操作

## 脚本说明

### package.ts（统一打包脚本）

主打包脚本，支持 DEB 和 DMG 格式。

**功能**:
- 自动检测架构
- 验证可执行文件存在
- 创建包结构
- 添加文档
- 生成安装包

### build_deb.ts（DEB 包装器）

向后兼容的 DEB 打包脚本，内部调用 `package.ts`。

**用法**:
```bash
bun run script/build_deb.ts [--arch amd64|arm64]
```

### build_dmg.ts（DMG 包装器）

向后兼容的 DMG 打包脚本，内部调用 `package.ts`。

**用法**:
```bash
bun run script/build_dmg.ts [--arch arm64|x64]
```
