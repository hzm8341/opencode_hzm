# OpenCode Desktop v1.1.4 - macOS Release

## 🎉 新版本发布

OpenCode Desktop macOS 版本现已发布！

## 📦 下载

### macOS (Apple Silicon / M1/M2/M3)
[下载 OpenCode_1.1.4_macOS.dmg](https://github.com/hzm8341/opencode_hzm/releases/download/v1.1.4/OpenCode_1.1.4_macOS.dmg)

- **文件大小**: ~66 MB

## 🚀 快速开始

### 安装步骤

1. **下载 DMG 文件**
   - 点击上方下载链接或从 Releases 页面下载

2. **打开并安装**
   - 双击下载的 DMG 文件
   - 将 `OpenCode.app` 拖拽到 `Applications` 文件夹

3. **启动应用**
   - 打开 Finder，进入 `Applications`
   - 双击 `OpenCode.app` 启动

### ⚠️ 首次运行提示

如果 macOS 提示"无法打开，因为来自身份不明的开发者"：
- 右键点击 DMG 文件或应用
- 选择"打开"
- 在安全提示中点击"打开"

## 📋 系统要求

- **操作系统**: macOS 10.13 (High Sierra) 或更高
- **推荐版本**: macOS 12.0 (Monterey) 或更高
- **架构**: Apple Silicon (M1/M2/M3) 或 Intel (x86_64)
- **磁盘空间**: 至少 200 MB 可用空间
