OpenCode GUI 安装程序
=====================

使用方法：
---------

方法 1: 双击运行（如果支持）
  双击 install-opencode.sh 文件

方法 2: 命令行运行
  chmod +x install-opencode.sh
  ./install-opencode.sh

方法 3: 直接使用 GUI 安装程序
  sudo bash install-gui.sh opencode_*.deb

系统要求：
---------
- Ubuntu/Debian Linux
- zenity (会自动安装)
- 管理员权限

注意事项：
---------
- 安装过程中可能需要输入管理员密码
- 首次运行会自动安装 zenity（如果需要）
- 安装完成后可以配置 API 密钥
